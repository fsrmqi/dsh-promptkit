# 接口文档生成

把别人对接你接口时要问的问题，一次性写成文档：字段表、示例、错误约定都有了，就不会反复"在吗？这个参数啥意思"。

## Prompt

```
根据下面的接口信息，生成一份可直接交接的接口文档：【粘贴接口签名、路由、Schema、已有注释，或直接描述接口需求】。

文档包含：

1. 请求总览——方法、路径、鉴权方式、Content-Type；
2. 请求参数表——字段名 / 类型 / 必填 / 说明 / 默认值 / 枚举值，按 path / header / query / body 分组；
3. 响应结构——成功响应体字段表 + 示例；错误码表（对应什么场景、调用方如何处理）；
4. 完整示例——一个真实可用的请求示例 + 对应的成功响应 + 一个失败响应；
5. 边界与约定——超时、幂等性、限流、分页、敏感字段的脱敏、空值行为。

规则：
- 只基于你拿到的接口信息书写，缺失字段标【待确认：…】，不要编造或脑补字段；
- 字段表用 Markdown 表格，示例用代码块；
- 字段说明要写"为什么存在"或"什么场景使用"，别只复制类型叫法。
```

## 适用场景

给别人（前端、对接方、测试）提供的接口文档、没走 OpenAPI 的手工接口、老接口补文档。

## 要点

- 五段式：请求总览 → 参数表 → 响应结构 → 完整示例 → 边界与约定
- 字段表必须给"用途/场景"，示例必须含一个成功 + 一个失败
- 未知字段标【待确认】，绝不脑补
- 输出 Markdown 表格 + 代码块，可直接粘贴
