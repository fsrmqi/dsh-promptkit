# 项目文档同步

适用于“代码已改，文档需要跟上”的项目维护任务。它只覆盖与本次代码改动直接相关的文档，不把文档同步扩大为全仓审计或重写。

## Prompt
```
请结合当前项目与近期代码改动，同步更新直接相关的文档。

先确认本次改动影响的模块、公开行为或配置，再定位对应的 README、docs、CHANGELOG 或使用说明。只更新与这些改动直接相关的内容，保持原有语言、结构和写作风格；以当前代码和已验证配置为准，不补写无法确认的功能描述。

完成后简要列出更新过的文档及其对应改动；无法从现有信息确认的部分请明确标注，不要臆测。
```
