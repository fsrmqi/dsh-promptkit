# 数据分析与验证

拿到一堆数据，最常见的两种错：急着下结论，或者只给出一堆数字没有结论。

这个 Prompt 逼着做四步——先体检、再探索、再下结论、最后给行动，而且**每个结论都标注证据强度**。

## Prompt

```
请对下面的数据/需求做一次完整的数据分析：
【粘贴数据样例、字段说明、或直接描述你想分析的问题】

按四个阶段输出：

1. 数据体检——列出主要字段、类型、粒度、缺失情况、重复、明显异常；一句话总结这份数据"能不能用、最要紧的坑在哪"；
2. 探索性分析——针对我的目标提出 3-5 个可检验的问题假设；用你能做的方式检查（分组、时间序列、相关性、分布、Top/Bottom）；每个发现写清楚"你看到了什么"；
3. 验证与结论——逐条回答原始问题；每条结论标注证据强度：【数据支持 / 部分支持 / 证据不足 / 与直觉相反】；需要统计检验的地方说明该用什么检验；
4. 行动建议——给 3 条可执行建议，标清楚每条依赖的数据和前提；缺什么补充数据、什么条件下结论会翻转。

规则：
- 关键数字注明出处；如果是我没提供的数据，你要么用【估算】标注、要么写"需要你提供"；
- 无法判断的写"无法判断"，不要用相似数字补位；
- 区分"数据表现的"与"我的解释"；
- 最后单独给"这份分析最不能确定的部分"。
```

## 适用场景

月度报表解读、产品数据分析、实验数据复盘、给别人讲"数据说明什么问题"。

## 要点

- 四阶段：体检 → 探索 → 结论 → 行动
- 每个结论标注证据强度【强/中/无法判断/相反】，是这套方法的核心
- 数字必须能溯源，待补数据标【估算】或直接开口要
- 收尾主动交底"最不能确定的部分"，防自话自说
