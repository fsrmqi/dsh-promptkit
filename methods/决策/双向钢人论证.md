# 双向钢人论证

这个 Prompt 前两天专门写过一篇：《一个极度实用的深度思考Prompt，帮你挖出最本质的答案》。

> 有人说跟 grill me 有啥区别——**底层逻辑不一样**：grill me 是帮你更好地提出问题，这个是在你有答案之后、不知道选哪个时做决策用的。

大家如果有犹豫不决的选择，不妨试试。

## Prompt

```
我需要做的决定是：【写清问题、两个选项、目标和现实约束】。

先别急着回答，也别默认我已经把问题想清楚。请先做一次双向钢人论证：

1. 用最完整、有力的方式，重述我真正需要做出的选择；
2. 分别给出支持两个方向的最强理由、适用条件、最大收益、最大风险，以及最难回答的反对意见；
3. 找出双方真正的分歧、最可能改变结论的关键变量，以及还需要补充的信息；
4. 只问我一个最可能改变结论的问题。

等我回答以后，再给出明确判断、理由、适用条件和下一步行动。
```

## 要点

- "钢人论证"：把两个方向各自最完整、最强有力的理由都摆出来（而非"稻草人"式弱化对方）
- 关键步骤：找出**真正分歧** + **最可能改变结论的关键变量**
- 最后只问**一个**最可能改变结论的问题，回答后再给判断
- 适用：犹豫不决的两个选项之间做选择
