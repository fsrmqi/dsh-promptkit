# 论文深度拆解

读一篇论文，最怕"读完了感觉懂了，但要讲给别人或复现时发现哪都没懂"。

这个 Prompt 把"读论文"变成"拆论文"：结论、方法、证据强度、坑、能怎么用，一次性逼出来。

## Prompt

```
请把这篇论文拆解成一份可复用的档案。信息如下：
【粘贴论文标题、摘要、原文节选，或告诉我要拆解的论文】

按这个顺序输出：

1. 一句话贡献——这篇论文做了什么事，和已有方法比，真正的差异点是什么；
2. 问题与研究线——它解决什么问题，为什么这是个真问题，跟主流方案的位置关系；
3. 方法——把方法拆到"能讲给别人听"的粒度：模型/框架/关键公式/训练与推断流程；与标准方法的差异点；
4. 实验与证据——数据集、基线、指标、消融实验；哪些证据强、哪些弱、是否有统计显著性说明；
5. 局限与盲区——作者自承认的局限 + 你没看到验证的盲区 + 它没说清的假设；
6. 可复现性评估——需要的依赖/超参/算力、原始数据可得性、复现最可能卡在哪；
7. 我能怎么用——把论文对接成具体建议：可借用方法 / 可补的实验 / 可避免的坑，按重要度排序。

规则：
- 只基于我提供的论文内容与它的信息；你记忆中关于它的常识要用的时候标【常识】，不确定标【待确认】；
- 事实、论文的声称、你自己的推断三者分开写；
- 输出 400-800 字左右正文，最后给我"下一步值得看的 3 篇或问题"。
```

## 效果

读完一张卡片，就能跟人讲清楚"它做了什么、证据够不够、我该怎么用"。

## 要点

- 七段式：定位 → 研究线 → 方法 → 证据强度 → 局限 → 可复现性 → 我该怎么用
- "论文明说的"与"我的推断"分开标注
- 实验部分专门问"哪些证据强、哪些弱"，逼出对证据质量的判断
- 收尾给 3 个"下一步"（可借用/可补实验/可避坑）
